# ytdlp-korean-interface v2.19.1-karon.1

Windows x64용 첫 KaronLabs 바이너리 릴리스입니다.

직접적인 upstream은 `ErrorFlynn/ytdlp-interface v2.19.1`이며, 실제 미디어 추출·다운로드 엔진은 `yt-dlp`를 사용합니다. KaronLabs는 변경하지 않은 upstream 코드의 단독 저작자를 주장하지 않습니다.

## Highlights

- 유지보수 가능한 C++ 소스로 복구한 한국어 UI
- `ko-KR` 카탈로그 검증과 안전한 English fallback
- 표시 문자열과 내부 queue/state token 분리
- 설정 복구와 검증된 `yt-dlp` nightly update/rollback 경로
- clean source, dependency, linker input, toolchain을 기록하는 candidate attestation
- Windows x64 Release build
- `127.0.0.1` fixture를 사용한 자동 artifact/runtime MP3 smoke
- 최종 배포 ZIP 전체를 다시 묶는 release-level provenance inventory

Headless release workflow는 candidate GUI 프로세스가 정상적으로 시작되는지 확인하고, 같은 실행 candidate의 `yt-dlp`/FFmpeg를 사용해 localhost MP3 산출물을 검증합니다. UI 버튼 클릭을 기계적으로 증명했다고 주장하지 않습니다.

## Verify the download

공개 ZIP은 `SHA256SUMS.txt`의 SHA-256과 비교할 수 있습니다.

ZIP 내부의 `release-manifest.json`은 최종 배포 파일 전체의 SHA-256/크기와 source/upstream/smoke 정보를 기록합니다. `candidate-manifest.json`은 그보다 앞 단계인 sealed build candidate의 source/dependency/toolchain provenance와 파일 inventory를 기록합니다.

번들된 `yt-dlp.exe`는 릴리스 빌드 시점의 공식 `yt-dlp/yt-dlp-nightly-builds` nightly이며, 정확한 tag와 SHA-256은 `release-manifest.json`에 고정됩니다.

워크플로가 실제로 릴리스한 KaronLabs source commit SHA는 게시 시 이 문서 뒤에 자동으로 추가됩니다.

작은 일이었는데 작지 않게 됐습니다.
